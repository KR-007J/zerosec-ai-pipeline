An L L M agent with direct tool execution is a security vulnerability waiting to happen. If you connect LangChain to a shell or database without a deterministic guardrail, an attacker can bypass your system prompt in seconds. Today, we are setting up NeMo Guardrails to stop jailbreaks and prompt injection at the runtime layer.

Prompt injection isn't a bug you can fix with a longer system prompt. Attackers use payload splitting, delimiter injection, and role-playing attacks to override developer instructions. . Traditional reg ex and keyword blocklists fail because natural language is infinitely combinatorial. NeMo Guardrails, developed by NVIDIA, solves this by intercepting user inputs before they reach the model  checking responses against programmable Colang execution flows. .
